# Model card — Combined Mutation + CNA Random Forest

**Intended purpose:** Educational, retrospective binary classification of *highest recorded* Stage IV versus Stages I–III prostate cancer using public MSK 2024 targeted-panel genomic data. This is not a model for screening, diagnosis, future metastasis risk, treatment selection or clinical triage.

**Model architecture:** scikit-learn `Pipeline(VarianceThreshold, RandomForestClassifier)`; 300 trees, Gini criterion, `min_samples_leaf=5`, `max_depth=None`, random seed 42. The mutation/CNA combined input contains 681 original features; 634 nonconstant features were retained by the fitted pipeline. Mutations are binary presence indicators for genes covered by every panel; CNA features use original discrete calls. The model was selected using validation AUROC, then refitted on 1,671 train+validation patients.

**Data provenance and populations:** Public cBioPortal MSK `prostate_msk_2024`, 1,967 eligible patients after stage filtering, one sample per patient. Source stage labels: 943 Stage I–III / 1,024 Stage IV. Model development split: train 1,376, validation 295, test 296 (142 Stage I–III, 154 Stage IV). Study population is selected from a single clinical/genomic study; demographic representativeness and generalizability have not been established.

**Held-out evaluation (296 patients):**

| Metric | Value |
|---|---:|
| AUROC | 0.6603 |
| 95% bootstrap AUROC CI (1,000 resamples) | 0.6003–0.7190 |
| Average precision | 0.6637 |
| Accuracy, threshold 0.5 | 0.6351 |
| Sensitivity | 0.7013 |
| Specificity | 0.5634 |
| Brier score | 0.2350 |
| True negatives / false positives | 80 / 62 |
| False negatives / true positives | 46 / 108 |

**Model interpretation:** Global random forest impurity-based feature importance highlights mutation features including TP53. Importance does not indicate causality or individual-specific explanations, and can be biased by predictor distributions.

**Known limitations:** Highest recorded registry stage may differ from stage at specimen collection; 349 Stage I–III patients have metastatic biopsy labels. Selection based on common sequencing-panel genes discards some genomic information, and 211 unmatching mutation records were excluded (potential aliases). Infrequent variants create sparse predictors; 174 CNA values of `-1.5` were retained without final source-specific interpretation. The model has not been externally validated. Probability calibration is imperfect; predicted probabilities are not clinically trustworthy confidence estimates.

**Not appropriate for:** Clinical decisions, diagnosis, patient-specific prognosis, treatment selection, patient groups outside the study without external assessment, unsequenced genes, incompatible gene panels/assays, individual patients with missing or unknown genomic feature coverage. Do not feed identifiable patient records to the public demonstration.

**Access / reproducibility:** The `.joblib` file is generated by `notebooks/03_model_training.ipynb`, not distributed with the public research repository.
